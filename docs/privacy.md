# سياسة الخصوصية — إدارة اتحاد الملاك

آخر تحديث: 25 سبتمبر 2026

توضح هذه السياسة كيفية تعامل تطبيق **إدارة اتحاد الملاك** مع البيانات اللازمة لتقديم خدمات إدارة المباني والملاك والمصروفات والدفعات.

## البيانات التي قد تتم معالجتها
- بيانات الحساب: الاسم، اسم المستخدم، رقم الجوال، البريد الإلكتروني، وبيانات التعريف التي يضيفها المستخدم أو مدير النظام.
- بيانات المبنى والوحدات والملكية المرتبطة بالحساب.
- بيانات المصروفات والدفعات والملاحظات والمرفقات التي يضيفها المستخدم.
- رمز إشعارات الجهاز (Push Token) لغرض إرسال التنبيهات المتعلقة بالمبنى والحساب.

## أغراض الاستخدام
تستخدم البيانات لتسجيل الدخول، إدارة المباني والملاك، عرض المصروفات والدفعات، إرسال الإشعارات، دعم المستخدم، وحماية الخدمة ومنع إساءة الاستخدام.

## مشاركة البيانات
لا تباع البيانات الشخصية للمعلنين. قد تتم معالجة البيانات بواسطة مزودي البنية التحتية والخدمات التقنية الضروريين لتشغيل التطبيق، وبالقدر اللازم لتقديم الخدمة.

## الاحتفاظ والأمان
يتم الاحتفاظ بالبيانات للمدة اللازمة لتقديم الخدمة والوفاء بالالتزامات النظامية أو المحاسبية عند انطباقها، مع تطبيق إجراءات تقنية وتنظيمية مناسبة لحماية البيانات.

## حذف البيانات
يمكن طلب حذف البيانات المرتبطة بالحساب عبر تعليمات حذف البيانات:
https://pm.sa/data-deletion.html
